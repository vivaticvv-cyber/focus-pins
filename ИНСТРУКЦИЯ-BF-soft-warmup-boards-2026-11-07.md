## Что изменено относительно пакета Клода

1. **Мягкий прогрев BF30 начинается уже сейчас** (с 8 ноября), а не с 16.11.
2. Три фазы публикации пинов с кодом `bf30` (в link или description):

| Фаза | Даты | Сколько BF-пинов всего к концу фазы | Характер |
|------|------|-------------------------------------|----------|
| Soft | 8–15 ноября | максимум **2** | очень редко, спокойно |
| Warm | 16–25 ноября | максимум **5** | чаще / сильнее |
| Active | 26–30 ноября | все оставшиеся (~1 в день) | каждый день |

3. Генерация картинок для BF-пинов теперь приоритетна уже сейчас (BF_GENERATE_DAYS_BEFORE=3).
4. Остальная логика Клода сохранена: тематические доски, NEW_BOARD_SHARE=0.5, NEW_PROMO_SHARE=0.6, board_map, pins_batch_16.
5. Пин 385 («Black Friday Tips» без кода bf30) **не** считается BF30-пином и может выходить в любое время.

Всего BF30-пинов в текущем pins.csv ≈ 8. График выше рассчитан именно на это количество.

## Пошагово после загрузки

### Шаг 1. Загрузить 4 файла
1. Открой репозиторий → Add file → Upload files.
2. Перетащи все 4 файла сразу: `publish.py`, `generate.py`, `board_map.csv`, `pins_batch_16.csv`.
3. Коммит: `Тематические доски + soft BF30 с 8.11 (фазы soft/warm/active)`.
4. Commit directly to main.

### Шаг 2. Слить партию (Merge)
1. Actions → **Merge pins batch** → Run workflow.
2. Дождись зелёного статуса (15–30 сек).
3. В логе должно быть примерно:
   - `board_map.csv: перенесено на тематические доски N пинов`
   - `Добавлено 28 строк из pins_batch_16.csv`
   - итоговое число строк в pins.csv ≈ 463 (или больше, если уже были добавления).

### Шаг 3. Проверка lint + dry-run
1. Actions → **Daily pins** → Run workflow → mode = `lint`.  
   Ожидание: `с замечаниями: 0`.
2. Снова Daily pins → mode = `dry-run`.  
   Смотри строки `DRY пин ...`. Должны появиться разные доски (новые тематические) и **не больше 1–2** BF30-пинов (soft-фаза).
3. По желанию: mode = `check` (связь с Buffer).

### Шаг 4. Сгенерировать картинки (если нужно)
Если в dry-run видны BF-пины со статусом new без картинки:
- Actions → **Autopilot** (или Generate) → Run workflow.
- Либо дождись ближайшего автоматического запуска Autopilot.
BF-пины теперь в приоритете генерации.

### Шаг 5. Дальше всё само
- Ближайший Daily по расписанию начнёт ставить пины по новой схеме.
- Soft-фаза (сейчас–15.11): максимум 2 BF30-пина всего.
- С 16.11 частота вырастет.
- 26–30.11 — оставшиеся почти каждый день.
- После 1 декабря оставшиеся BF30-пины просто перестанут выбираться (окно закрыто). Их можно будет позже удалить из pins.csv.

## Откат (если что-то пойдёт не так)

В `publish.py` найди блок:
```python
NEW_BOARDS=( ... ),
```
и замени на:
```python
NEW_BOARDS=(),
```
Выбор досок вернётся к старому порядку «по id».  
Либо верни предыдущую версию `publish.py` из истории коммитов.

Чтобы полностью отключить BF-фильтр (не рекомендуется): поставь  
`BF_WINDOW=("2026-01-01", "2026-12-31")` и `BF_SOFT_MAX=999`.

## Что НЕ нужно делать
- Не загружай старые версии publish.py / generate.py поверх этих.
- Не правь pins.csv вручную без необходимости.
- Не удаляй board_map.csv сразу — он применится при первом load_rows / merge. После успешного прогона его можно удалить (по желанию).
