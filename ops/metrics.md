## Краткий вывод по воронке (31.10)

```
Соцсети → ~3500 impressions → 13–20 outbound → Gumroad 156 views → real trials 0 → paid 0
```

1. **Paid sales = 0. Real trial starts = 0** (единственный free = тест владельца 29.09).
2. **Узкое место №1:** discovery / reach. Алгоритмы почти не показывают контент.
3. **Узкое место №2:** outbound. Даже увиденные посты почти не кликают (Pinterest 2140 → 13).
4. Trial → paid воронка не тестировалась — до trial почти никто не доходит.
5. Поиск (GSC) практически нулевой.
6. Соцсети (FB/X) дают единичные клики; Pinterest — единственный канал с заметным (но всё равно мизерным) outbound.

**Вывод для стратегии:** пока outbound ≈ 0, улучшать страницы продуктов бессмысленно. Приоритет — увеличить реальные переходы из существующих каналов (в первую очередь Pinterest + явные CTA на trial).

## Правило решения на 01.11
- нет трафика на страницы товаров → проблема в источниках трафика
- трафик есть, на товар не идут → ссылки / посадка
- на страницы приходят, но не покупают → страница, цена, доверие (отзывов и продаж пока нет)
